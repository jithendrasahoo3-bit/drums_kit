# Online Drum Kit 🥁

An interactive web-based drum kit built with vanilla HTML5, CSS3, and modern JavaScript. Play your beats with mouse clicks, touch taps, or keyboard shortcuts.

**Live Demo:** [https://jithendrasahoo3-bit.github.io/drums_kit/](https://jithendrasahoo3-bit.github.io/drums_kit/)

---

## Features

- **Low-Latency Audio**: Pre-loaded audio elements with instant replay for rapid drumming.
- **Keyboard & Touch Controls**: Seamless support for both desktop keyboard inputs and mobile touch taps.
- **Visual Feedback**: Snappy active-press animations and distinct drum illustrations.
- **Responsive Layout**: Adapts cleanly across mobile, tablet, and desktop screens.

## How to Run Locally

1. Clone this repository:
   ```bash
   git clone https://github.com/jithendrasahoo3-bit/drums_kit.git
   ```
2. Open `index.html` in your web browser.
3. Click **Start Playing** and make some beats!
